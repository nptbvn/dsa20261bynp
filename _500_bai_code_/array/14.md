# Shuffle an array using Fisher–Yates shuffle algorithm
- Pseudocode (đc cung cấp cùng nguồn của bộ bài tập):
To shuffle an array ‘a’ of ‘n’ elements:for i from n-1 down to 1 do    j = random integer such that 0 <= j <= i    exchange a[j] and a[i]
- do cần random hàm random đc gọi từ thư viện tích hợp sẵn: stdlib và time
